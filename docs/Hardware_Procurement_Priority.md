# AfterMotion 原型硬件采购优先级

## 采购目标

本清单服务于十天作品集 MVP。采购顺序以验证核心产品假设为标准，不以一次完成可穿戴成品为目标。

第一阶段需要证明：

1. IMU 能记录一次运动的加速度和角速度；
2. Recovery Band 能在固定位置和固定起始张力下重复读取 Stretch 与 Temperature；
3. 数据可以通过 USB 串口或手动录入进入 App；
4. 左右膝和运动前后的结果可以形成 Recovery Curve。

BLE、电池、独立双设备和可穿戴外壳不是第一批采购的阻塞项。

## 采购原则

- 购买开发板或 Breakout Board，不购买需要自行焊接的裸芯片；
- 优先购买已焊排针或带 Qwiic、STEMMA QT 接口的模块；
- 所有模块需支持 3.3 V 逻辑；
- 第一阶段使用 USB 供电，不立即使用锂电池；
- 容易损坏或批次差异较大的部件购买备用件；
- 商品标题不足以确认型号时，核对芯片丝印、原理图和引脚说明；
- 不因“医疗级”营销描述支付溢价，MVP 不作医疗准确度声明。

### Priority 0 选择说明

ESP32-S3 DevKitC-1 具备 BLE、USB 和完整 GPIO 引出，适合面包板和跳线连接。BMI270 是针对可穿戴场景的六轴 IMU，可提供三轴加速度和三轴角速度。TMP117 使用 I2C，低功耗且在人体温度附近具有较高精度，适合先验证接触温度趋势。

Conductive Rubber Stretch Sensor 不是线性精密传感器，并且释放后可能需要一段时间恢复。它适合验证相对变化和重复测量流程，但不能直接声称输出医学级毫米围度。

## 暂不采购

- 裸 BMI270 或裸 TMP117 芯片；
- 定制 PCB；
- 医疗级昂贵测量设备；
- 多套不同型号 MCU；
- 蜂窝网络或 GPS 模块；
- 显示屏；
- 大容量电池；
- 防水封装材料；
- 量产模具；
- 未确认协议和示例代码的廉价无品牌 BLE 模块。

## 到货后的验证顺序

### Test 1 ESP32-S3

- USB 连接和串口识别；
- 烧录基础程序；
- 输出稳定时间戳；
- BLE 广播测试。

### Test 2 BMI270

- I2C 地址识别；
- 静止时读取三轴加速度与角速度；
- 50 Hz 连续采样；
- 导出至少一分钟 CSV；
- 检查丢帧和时间戳连续性。

### Test 3 TMP117

- I2C 地址识别；
- 1 Hz 连续采样；
- 室温静置五分钟；
- 皮肤接触五分钟；
- 记录达到稳定读数所需时间。

### Test 4 Stretch Sensor

- 测量静止电阻；
- 使用分压电路读取 ADC；
- 对固定长度重复拉伸十次；
- 记录回弹、迟滞和漂移；
- 比较两种固定起始张力结构。

### Test 5 Combined Prototype

- 同一 ESP32-S3 同时读取 BMI270、TMP117 和 Stretch Sensor；
- 首先通过 USB 串口输出；
- 数据稳定后再开发 BLE；
- 最后再迁移到电池和可穿戴结构。

## 安全说明

- 初期一律使用 USB 供电，避免边运动边佩戴裸露电路；
- 锂电池阶段必须使用带保护的电池和匹配的充电模块；
- 不使用鼓包、破损或来源不明的 LiPo；
- 皮肤接触部分需隔离焊点、导线端部和尖锐结构；
- 台架原型未经固定和绝缘前，不进行跑跳、急停或对抗运动；
- 原型数据只用于趋势验证，不用于医疗判断。

### Elastreme 接入决定

转接板输出范围为 0–5 V，不能直接连接 ESP32-S3 ADC。台架测试使用两个 20 kΩ、1% 电阻组成 1:1 分压，将最大输入电压降至约 2.5 V：

```text
转接板 OUT
    │
   20 kΩ
    │
    ├──── ESP32-S3 ADC
    │
   20 kΩ
    │
   GND
```

第一次连接 ESP32-S3 前，先用万用表确认分压节点在传感器整个拉伸范围内不超过 3.0 V。
